# Documentation fonts

These are the unchanged font files bundled with the previously used
`3dmol/clean-jsdoc-theme` fork (version 4.2.14). Keeping them local preserves the
old documentation typography without depending on a font CDN.

| File | Font version | Weight |
| --- | --- | --- |
| `WorkSans-Bold.ttf` | 2.012 | Bold (700) |
| `OpenSans-Regular.ttf` | 3.000 | Regular (400) |
| `Inconsolata-Regular.ttf` | 3.001 | Regular (400) |

All three font files identify the SIL Open Font License, Version 1.1, in their
embedded metadata. The accompanying license files retain the corresponding
copyright notices and were obtained from the official Google Fonts repository:

- [Work Sans license](https://github.com/google/fonts/blob/main/ofl/worksans/OFL.txt)
- [Open Sans license](https://github.com/google/fonts/blob/main/ofl/opensans/OFL.txt)
- [Inconsolata license](https://github.com/google/fonts/blob/main/ofl/inconsolata/OFL.txt)

The embedded Inconsolata copyright also identifies its project repository:

(https://github.com/cyrealtype/Inconsolata).
